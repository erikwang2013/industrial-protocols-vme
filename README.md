# VME/VPX 协议包 — 工控背板总线，需 VME 桥接模块

> [English](README.en.md)

VME (Versa Module Europa) / VPX 工控背板总线协议。用于军工/航天嵌入式系统，需要 VME 桥接模块，通过内核 Bridge 层桥接。

## 安装

```bash
composer require erikwang2013/industrial-protocols-vme
```

## 功能

VME/VPX 总线桥接、BridgeConnector 连接管理

## 所需硬件

VME 桥接模块（Tundra Universe II / Tsi148 等）

## 兼容框架

Laravel / Webman / Hyperf / ThinkPHP / Yii2 / Yii3 / Plain PHP

## 系统要求

- PHP >= 8.1
- VME 桥接硬件
- erikwang2013/industrial-protocols-kernel
